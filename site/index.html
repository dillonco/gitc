What's in the box

Dense where it counts, quiet everywhere else.

One window, no tabs to babysit. The graph, the diff, and the working tree are always a glance apart, and everything below is already wired up.

01

The graph, drawn properly

Lanes, merge edges, and ref pills for every branch and tag. Search the history by message, author, hash, or ref and jump straight to the commit.

02

Stage by the hunk

Flat or tree view of the working copy, unified or side-by-side diffs, and stage / unstage / discard at the hunk level — so the commit you write is the commit you meant.

03

Merges without the dread

A progress banner with continue and abort while a merge or rebase is in flight, and a conflict editor that shows base, ours, theirs, and your resolution. Nothing is written until you save.

04

Careful by default

Pull is fast-forward only. Force-push always takes --force-with-lease. Destructive actions can be gated behind a confirmation, and that gate is a setting, not a lecture.

05

The rest of the toolbox

Branches and remote tracking, tags, stashes, worktrees, blame, per-file history, cherry-pick, revert, and reset — all reachable from the commit you're looking at.

06

Knows where you work

Point it at any local repository by path. Recent repositories persist across launches, so Monday morning starts where Friday left off.

Under the hood

It runs git. Literally.

The Rust core doesn't reimplement git — it drives the git CLI you already have installed and trusts its answers. Whatever your hooks, config, and credential helpers do on the command line, they do here too.

  • Svelte UI in a native webview via Tauri, so the app stays small and starts fast.
  • Every mutation goes through real git commands — your reflog tells the true story.
  • npm run dev:ui serves the interface in a plain browser with a demo repository, no Rust toolchain needed.
gitc → git
graph     git log --all --topo-order --parents
stage     git apply --cached hunk.patch
pull      git pull --ff-only origin main
push      git push --force-with-lease origin fix/lanes
blame     git blame --porcelain src/lib/git.ts
Get it

Clone, build, done.

$ git clone https://github.com/dillonco/gitc
$ cd gitc
$ npm install
$ npm run build
# → src-tauri/target/release/bundle/macos/gitc.app

You'll need Node and a Rust toolchain. npm run dev starts the app with hot reload; npm run check keeps the TypeScript honest.

Just want to poke at the interface? npm run dev:ui runs it in your browser against an in-memory demo repo — no Rust, no risk to a real repository.
